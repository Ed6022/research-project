## General objective

Develop and evaluate a reproducible project workflow that addresses a clearly defined research or technical problem using appropriate evidence, methods, and validation criteria.

## Specific objectives

1. Define the project problem, scope, assumptions, constraints, and success criteria.
2. Review and organize the scientific or technical literature relevant to the project.
3. Design a methodology that connects project inputs, methods, analyses, and outputs.
4. Acquire, generate, or curate the data and supporting material required for implementation.
5. Implement the proposed workflow and document all significant methodological decisions.
6. Evaluate the results using predefined metrics, uncertainty analysis, baselines, or validation data.
7. Interpret the results in relation to the project objectives and the existing literature.
8. Produce a reproducible final package containing the report, code, data references, figures, and supporting documents.

## Research questions

Use this section to state the central question and supporting questions. For example:

- What measurable problem is the project trying to solve?
- What evidence is required to evaluate the proposed approach?
- Which methods provide an appropriate baseline?
- What criteria determine whether the project objectives have been met?

## Success criteria

Define measurable criteria before implementation begins. Examples include target accuracy, uncertainty bounds, completion of a validated prototype, comparison against a baseline, reproducibility requirements, or delivery of a documented dataset.
